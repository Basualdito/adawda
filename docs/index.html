Animaciones implementadas (GPU 60 fps)

  • Entrada del Hero: @keyframes heroFadeUp y heroCardIn con variable --hero-delay.
  • Bloques al scrollear: IntersectionObserver detecta cada .reveal-block y agrega .is-visible.
  • Barra superior de progreso: Escala horizontal (transform: scaleX) sincronizada con requestAnimationFrame.
  • Accesibilidad: Respeta prefers-reduced-motion: reduce para quienes prefieren menor movimiento.

Lógica reutilizable de copiado en js/script.js

copyButtons.forEach((btn) => {
  btn.addEventListener("click", async () => {
    const targetEl = document.getElementById(btn.dataset.copyTarget);
    const value = targetEl.textContent.trim();
    await copyText(value);
    showToast(btn.dataset.copyLabel);
  });
});

Con un solo bloque de código y atributos data-copy-target funciona tanto para copiar el correo como el teléfono.

Registro de Uso de IA (Resumen de bitacora_ia.md)

Consulta 1 — Estructura HTML y CV

Objetivo: Integrar los datos del CV real, competencias (Copa Robótica, Iron Bot, Tech Camp UCC) y proyectos técnicos en una estructura distinta (ficha técnica lateral + bento grid).

Decisión propia: Aclarar que el entrenamiento físico es experiencia práctica sin certificación formal y crear diagramas SVG propios.

Consulta 2 — Paleta Azul/Amarillo Tenue y JS

Objetivo: Implementar tokens CSS en tonos azules con amarillo tenue, animaciones GPU y copiado al portapapeles de correo y teléfono.

Decisión propia: Usar JavaScript puro sin librerías externas para mantener el código claro y fácil de defender oralmente.

Guía rápida para explicar el código al docente

Si te preguntan... Qué responder y dónde mostrarlo
¿Dónde están los colores azules y el amarillo tenue? En css/estilos.css dentro de :root (--blue-950 a --blue-50 y --yellow-50 a --yellow-300).
¿Cómo funcionan los filtros de proyectos? En js/script.js: cada botón tiene data-filter y cada tarjeta data-category; al hacer clic se alterna la clase .is-hidden.
¿Cómo hiciste el modal de evidencias? En index.html (#evidence-modal con role="dialog") y js/script.js, cerrando con botón ✕, clic afuera o tecla Escape.
¿Por qué las imágenes son archivos .svg? Porque son gráficos vectoriales livianos que no pierden nitidez al ampliarse en el modal y no dependen de servidores externos.

Pasos para publicar en GitHub Pages

  1. Creá un repositorio público llamado exactamente tuusuario.github.io.
  2. Subí el contenido de la carpeta manteniendo index.html en la raíz junto a css/, js/, assets/, docs/, README.md y bitacora_ia.md.
  3. Abrí Settings → Pages en GitHub.
  4. En Source elegí Deploy from a branch, seleccioná main y /(root), y tocá Save.
  5. Esperá unos minutos y verificá la URL pública https://tuusuario.github.io.
